AUTONOMOUS BY DESIGN

Loops and checks

The cycle, the mailbox, the runner script and the guardrails, modeled on the Koboo launcher. The scheduler does not run it yet.

Proposed design

Loops

LoopCadenceWhat it checksIf it fails
Cycleper taskBuild, run hard checks, run a read-only review, keep or undo.Undo and keep a patch as failure evidence.
Runner pollevery 15 secondsWorker alive, time box not passed, status refreshed.Past the time box: stop the process tree and undo.
Watchdogevery 15 minutesHeartbeat, log growth, elapsed vs estimate, idle worker with ready work, queue depth.Nudge, restart the runner, then escalate. Warn at 2x the estimate, escalate at 4x.
Allowance retryevery 15 minutesProvider usage allowance.Wait and keep checking; other lanes continue.
Test cap10 minutesTest run finishes.Stop the tests and send the hang back as a repair instruction.
ReviewerscheduledReview kept and undone tasks, keep at least 5 queued.After 3 failures, park the task with a diagnosis.
Standalone plannerqueue emptyPlans 1 to 3 small tasks through the same checks.3 undone in a row: pause 1 hour. 5 tiny in a row: pause 30 minutes.
Self-updatebetween tasksNew launcher or guide files wait in the mailbox, get installed, runner reloads.A bad update falls back to the last good launcher.

The Markdown mailbox

inbox\New tasks written while the builder is busy; moved into the queue between tasks.
inbox\files\<path>New versions of tracked files, installed and committed between tasks.
queue\ done\ failed\One task file per task; names sort in execution order.
results\Result and review verdict per task, as JSON.
BUSY.txtExists while the builder works.
claude-reviewed.txtLast commit reviewed, for catch-up.

Each message gets a sequence number and an acknowledgement file, and is written to a temporary name then renamed, so a half-written task is never picked up.

Escalation ladder

Try differently, then park the item and move on, then change the lever (instruction revision, stronger model, another tool). Work continues the whole time.
