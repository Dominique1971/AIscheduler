HOW KEYS AND NAMES WORK

Keys sit in the Windows credential store or environment. The console reads only the reference name and a connected check. Adding a key is a local terminal command.

Names like "latest" resolve at run time from each provider’s model list and are pinned per run in the ledger. Subscription routes show usage windows, not dollars.
