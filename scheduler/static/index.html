Import a project plan

Create a Markdown intake file outside this dashboard, then upload it here for validation and review. Uploading does not start work.

Required Markdown format

Use the exact v1 headings and field labels. Include a project ID, name, runtime repository path, base branch, worker cap, project description, and at least one task. Each task needs an ID, title, description, positive minute estimate, dependency IDs or “none”, and acceptance criteria. Dependencies must point to other tasks and contain no cycles.

The dashboard currently imports new demo- or dummy- simulation projects under ./runtime/. Review the source hash, defaults, estimates, graph and diff before approving. Estimates are not delivery forecasts.
